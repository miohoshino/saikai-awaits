## 反映時に確認・決定すること

| 項目 | 確認したいこと | 仮の方針 |
|---|---|---|
| フォント | 候補から選ぶ | 丸ゴシック系（M PLUS Rounded 1c / Zen Maru Gothic / Kosugi Maru）。Google Fonts で読み込む |
| トップ画像 | Drive フォルダが共有リンクで閲覧できるか。どの画像をどのページに使うか | 画像をリポジトリの `public/` に置いて配信する |
| 下部メニュー | 詳細画面では「戻る」との併用でよいか | 詳細画面の上部に戻るボタン、下部にメニューを常に表示 |
| 反応しないボタン | ボタンごとの行き先 | ホームの「参加する」→ イベント詳細、おすすめの「参加する」→ コミュニティ参加、「詳細を見る」→ 仕事の詳細、ベル → マイページの「いいね！」欄、丸い写真 → マイページ、など |
| つながるのカテゴリー | 複数のタグを持つ人は複数のカテゴリーに出すか。どれにも当てはまらない人の扱い。タグの表記ゆれ（例: 「ＡＩ」「AI」） | 複数カテゴリーに表示。当てはまらない人は「その他」。全角・半角や大文字・小文字の違いは同じタグとして扱う |
| つながるのカテゴリー | 「地域のお店」に当たるタグの表記 | タグ「地域のお店」と一致するものを対象にする |
| コミュニティのイベント | イベントとコミュニティをどう結び付けるか | 投稿（entries）にコミュニティとの関連を追加する。ダミーイベントは開発用 seed に入れる |
| AWAITSニュースのページ | 何をどう並べるか | ニュース（GOOD NEWS）と仕事・募集を新しい順に1つの一覧で表示し、「すべて／ニュース／仕事・募集」で切り替えられるようにする。ホームの「AWAITSニュース」欄の「すべて見る」と、「みつける」から開く |
| みつけるのイベント情報 | 並び順と、終わったイベントの扱い | 開催日が近い順に表示し、開催日を過ぎたものは出さない。AWAITSニュースは最新数件を表示し、「すべて見る」で専用ページへ |
| チャレンジのカテゴリー | コミュニティ一覧の中でどう分けるか。チャレンジの「興味あり」はコミュニティの「参加」と同じ扱いにするか | 一覧上部に「すべて／コミュニティ／チャレンジ」の切り替えを置く。ボタンは種類ごとに今の動きを維持 |
| 参加コミュニティの履歴 | 退会した記録も履歴に残すか | 参加日を表示。退会も履歴として残す |
